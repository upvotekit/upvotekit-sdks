# UpvoteKit SDKs

First-party client SDKs for [UpvoteKit](https://upvotekit.com): feedback boards, roadmaps and changelogs for your
product.

| Package | Folder | Install |
| --- | --- | --- |
| Flutter SDK: the hosted board, roadmap and changelog in a webview | [`flutter/upvotekit`](flutter/upvotekit) | `flutter pub add upvotekit` |
| MCP server: lets AI agents work with your feedback through scoped API keys | [`mcp`](mcp) | `npx -y @upvotekit/mcp` |

Each package has its own README, CHANGELOG and MIT license.

For websites, use the script tag from your project's settings; no package is needed.

## Issues

Report bugs and ideas in [Issues](https://github.com/upvotekit/upvotekit-sdks/issues), or on our feedback board from
inside the app.

This repository is a read-only mirror, published from the UpvoteKit codebase; each commit is a sync. Pull requests
are welcome: we apply accepted changes there and close the pull request with a link to the release that carries
them. Releases are tagged `flutter-vX.Y.Z` and `mcp-vX.Y.Z`.
