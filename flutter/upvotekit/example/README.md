# UpvoteKit Flutter example

Minimal Android/iOS app demonstrating the `upvotekit` package.

```bash
flutter run \
  --dart-define=UPVOTEKIT_BASE_URL=http://localhost:3100 \
  --dart-define=UPVOTEKIT_PROJECT=acme
```

On the Android emulator, the default base URL is `http://10.0.2.2:3100` (host machine localhost).
